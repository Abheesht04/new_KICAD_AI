Paths are files on this computer: absolute (C:\work\board.kicad_pcb) or relative to the server's root folder. Verdicts come from the engine unchanged: PASS means the implemented rules ran and passed, UNVERIFIED means something could not be decided, and neither is a fabricator's acceptance.

1 · Board

Load a KiCad .kicad_pcb. The engine reads it exactly (integer nanometres) and reports what it holds.

2 · DFM against a fabricator

Checks the loaded board against a fab profile whose every limit cites the fabricator's page.

3 · Drill file check

Reads an Excellon file; with the loaded board, every hole must match a board hole.

4 · Fabrication export

Gerbers and drill files through kicad-cli (start the server with --kicad-cli). The output folder must not exist yet: nothing is overwritten.
